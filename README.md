# Агро-калькулятор посевных

Сайт с личным кабинетом: регистрация, вход и доступ к калькулятору нормы
высева. Только стандартная библиотека Python — ни Flask, ни базы данных
ставить не нужно (SQLite создаётся сама).

## Запуск

```powershell
cd agro_site
python app.py                  # http://127.0.0.1:8765
python app.py --port 9000      # другой порт
python app.py --host 0.0.0.0   # доступ из локальной сети (телефон, планшет)
```

Демо-доступ: **demo@agro.ru** / **demo12345** (создаётся при первом старте).
Или зарегистрируйте свой аккаунт — пароль от 8 символов.

## Что умеет

- Регистрация и вход, сессии в HttpOnly-cookie на 7 дней, пароли — PBKDF2-SHA256
  (200 000 итераций), CSRF-токен на формы и API.
- Калькулятор: культура, площадь, норма высева, масса 1000 семян, всхожесть,
  чистота, цена.
- Считает норму высева (кг/га), посевную годность, семена на гектар, общий
  объём в кг и тоннах, стоимость по полю и на гектар.
- Сохранение расчётов в историю (последние 20) и удаление записей.
- Адаптивная вёрстка: телефон, планшет, десктоп.

## Формула

```
посевная годность, % = всхожесть, % × чистота, % / 100
норма высева, кг/га  = норма (млн/га) × масса 1000 семян (г) × 100 / посевная годность
```

Проверка: пшеница 5,0 млн/га, масса 1000 семян 40 г, всхожесть 95%, чистота
99% → посевная годность 94,05% → 212,7 кг/га.

## Свои культуры

Справочник — словарь `CROPS` в `app.py`. Добавьте культуру и её значения
массы 1000 семян (`m1000`, граммы) и нормы высева (`density`, млн семян/га) —
она сразу появится в списке на сайте.

## Что учесть перед публикацией

- Сайт отдаёт HTTP; для интернета поставьте его за HTTPS-прокси (nginx, Caddy).
- Для нескольких сотен пользователей хватит и этого сервера; при росте —
  gunicorn/uwsgi или перенос на FastAPI/Django.
- Секреты не хранятся в коде: сессии и пароли — в базе, cookie непрозрачная.
- Регистрация открыта; если нужны только приглашённые — добавьте проверку
  домена почты в `_register`.

## Деплой на Render (бесплатно)

В папке уже есть `render.yaml` — Render подхватит настройки сам.

1. Залейте содержимое `agro_site` в репозиторий GitHub (чтобы `app.py` и
   `render.yaml` лежали в корне).
2. На [render.com](https://render.com) → **New → Blueprint** → выберите
   репозиторий: Render прочитает `render.yaml` и создаст web-сервис на
   free-плане.
   Либо вручную: **New → Web Service**, Runtime — Python,
   Build Command — `pip install -r requirements.txt`,
   Start Command — `python app.py`, Plan — **Free**.
3. Через пару минут сайт откроется на `https://<имя>.onrender.com`.

Сервер берёт порт из переменной `PORT`, слушает `0.0.0.0`, а health-check
Render ходит на `/healthz`.

**Ограничения free-плана:**
- инстанс засыпает после ~15 минут без запросов, первый запрос после сна
  идёт 30–60 секунд;
- диск эфемерный: `data.db` обнуляется при деплое и перезапуске, поэтому
  аккаунты и история расчётов между ними не сохраняются (демо-пользователь
  создаётся заново при старте).

Если нужна настоящая сохранность — подключите бесплатную PostgreSQL
(Neon, Supabase) и замените SQLite, либо возьмите платный инстанс Render
с постоянным диском ($7/мес) и направьте `DB_PATH` на него.
